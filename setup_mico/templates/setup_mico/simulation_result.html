    1. 결합 파라미터
    (Pre_Thk − Ref_Pre_VM) 에 곱하는 가중치
    RR_DB 로 나눈 보정량에 곱하는 가중치
    Simul_APC 상한 (비우면 미적용)
    Simul_APC 하한 (비우면 미적용)
    APC 가 제어하지 않는 앞단 고정 연마 step
    압력 1단위당 편차 변화량. 비우면 장비·레시피별로 데이터에서 회귀
    이보다 적으면 전체 데이터 회귀로 대체
    이보다 낮은 회귀는 버림 — 기울기가 0 에 가까우면 Simul_APC 가 발산
    Ref_Count 가 이 값이면 Linear 산식
    PRESSURE zone — 두께를 직접 맞추지 않고 13P(중심) 대비 편차를 0 으로 맞춥니다. 두께는 TIME 이 산출한 13P 시뮬 두께 + 편차 로 만들어지고, 시간 보정값인 Idle OFFSET 은 산식에서 제외됩니다.
    ※ 압력은 편차에 반응해 움직인 제어 출력이라 민감도 회귀가 closed-loop 이 됩니다 — 기울기가 실제보다 작게(또는 부호가 뒤집혀) 나올 수 있으니, 아는 값이 있으면 Bias Slope 에 직접 넣어 고정하세요.
